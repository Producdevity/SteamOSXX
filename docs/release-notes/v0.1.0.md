# SteamOSXX v0.1.0: first release

A flashable SD-card OS that boots the Anbernic RG40XX-H straight into Valve's native arm64 Steam client (Big Picture),
on a mainline Linux kernel. Windows games run through Proton ARM64 and FEX. This is an early release: it works, and
it is slow.

## Install

1. Download `steamos-rg40xx.img.xz` and `steamos-rg40xx.img.xz.sha256`, and check the hash
   (`sha256sum -c steamos-rg40xx.img.xz.sha256` in the download folder).
2. Write the image to a microSD card of 16 GB or more (balenaEtcher, or `xzcat steamos-rg40xx.img.xz | sudo dd of=/dev/sdX bs=4M conv=fsync`).
3. On the card's small `STEAMBOOT` partition, copy `wifi.txt.example` to `wifi.txt` and fill in `ssid=` and `psk=`.
4. Put the card in **slot 1** and power on. The first start grows the root partition, joins Wi-Fi, shows a
   "Setting up SteamOSXX" window while it downloads Valve's Steam client and a Proton build for this CPU, and then
   Steam's own update screen. Allow 15 to 30 minutes.
5. Sign in with the QR code. Games use the ARMv8.0 Proton automatically.

## Hardware

Tested on **one RG40XX-H with LPDDR4**. Other units can have different RAM timings; a wrong set gives a silent, black
boot and does no harm (keep your stock card). If the card does not boot, U-Boot shows it to a PC as a USB drive so it
can be rewritten. `fel-boot.bin` and `fel-reset.bin` are developer tools for booting through the USB boot mode.

## What works

Boot from slot 1, display, audio, Wi-Fi, controls through Steam Input, brightness and volume keys, Steam's power menu
(real power off), Steam Big Picture, and Windows games through Proton ARM64 and FEX. Games come to the front, the
Steam button opens the in-game menu and B returns, as on SteamOS.

## Known issues

- **It is slow.** Steam's UI is Chromium on four Cortex-A53 cores and 1 GB of RAM. Geometry Wars: Retro Evolved runs
  at about 6 to 9 FPS; a game takes one to two and a half minutes to start. Direct3D 9 renders on the Mali through
  WineD3D; Direct3D 10/11 titles fall back to DXVK on the CPU and are slower (set `PROTON_USE_WINED3D=0` in the launch
  options for those).
- **No sleep or wake.** The power menu's Suspend does not work.
- **The GPU cannot run DXVK or gamescope** (PanVK on this Mali is Vulkan 1.0 only). Steam's gamescope behaviour is
  emulated on Xorg.
- The screensaver settings are not applied by the current Steam build.
- **adb over USB is a root shell** without a password, and SSH accepts only keys (none are installed). Treat the
  device as yours alone.
- The first start downloads about 1 GB and needs Wi-Fi; there is no on-screen Wi-Fi setup yet, only `wifi.txt`.

# SteamOSXX v0.2.0: a native Steam Deck controller

The handheld's built-in controller now reaches Steam as a real **Steam Deck controller** (Valve `28de:1205`), so
Steam shows Deck glyphs and layouts and no longer shows its "External Controller Translation" dialog before a game's
first launch. It needed a kernel with HID support, so this release ships our own build of ROCKNIX's kernel.

## What's new

- **Native Steam Deck controller.** [InputPlumber](https://github.com/ShadowBlip/InputPlumber) presents the built-in
  pad to Steam as a Deck over a virtual USB device. Buttons, sticks, triggers and the D-pad work in Steam's UI and in
  games. Cost: about 2% of one CPU core and a few MB of RAM.
- **New kernel, `7.2.0-sxx`.** ROCKNIX's H700 7.2 kernel rebuilt with `HIDRAW`, `UHID`, `HID_STEAM` and the USB/IP
  virtual host, which the stock kernel lacks (Steam's own controller drivers for DualSense, Switch Pro and similar
  pads need `hidraw` too). Same patches, same device trees, the joypad driver rebuilt against it. The build is
  reproducible in CI (`kernel/build.sh`).
- **Steam's screensaver is off again**, matching the current Steam client; it had covered the game-launch prompt.
- **Steam no longer re-extracts its client on every start**, a first-start and restart delay fixed in v0.1.0.

## Installing

There is no in-place upgrade: this release changes the kernel and boot files, so write the image to a card as in the
v0.1.0 notes (`wifi.txt` on the boot partition, card in slot 1, allow up to an hour for the first start).

## Known issues

- **It is slow.** Steam's UI is Chromium on four Cortex-A53 cores and 1 GB of RAM; Geometry Wars: Retro Evolved runs
  at about 6 to 9 FPS and a game takes one to three minutes to start the first time. Direct3D 10/11 titles use DXVK on
  the CPU (set `PROTON_USE_WINED3D=0` in the launch options) and are slower.
- **No sleep or wake.** The power menu's Suspend does not work.
- **The GPU cannot run DXVK or gamescope** (PanVK on this Mali is Vulkan 1.0 only).
- After an unclean shutdown Steam spends a few minutes verifying its files before it starts.
- **adb over USB is a root shell** without a password, and SSH accepts only keys (none are installed).
- The first start downloads about 1 GB and needs Wi-Fi from `wifi.txt`.
- Only tested on one RG40XX-H with LPDDR4. Other units may need different RAM timings.

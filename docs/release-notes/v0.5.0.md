# SteamOSXX v0.5.0: Bluetooth, and updates that roll back

## What's new

- **Bluetooth.** The handheld's Bluetooth controller (the Wi-Fi chip's, RTL8821CS) was already recognised by the kernel;
  the image now has the Bluetooth stack (bluez) and PipeWire's Bluetooth audio, so Steam's Settings > Bluetooth page
  works and scans. Pairing a headset or controller has not been tried yet.
- **A bad update rolls itself back.** A release installed through Steam's Check For Updates is on trial until Steam's UI
  has stayed up for 30 seconds. If the new release fails to reach that three boots in a row, the next boot installs the
  previous release again (about ten minutes) and does not offer the failed one a second time. Tested on hardware with a
  deliberately broken release. The previous release is kept on the data partition (about 1.5 GB). Limits: it needs
  a previous release installed by the updater (a freshly flashed card has none), and a release whose kernel or initramfs
  cannot start at all cannot run the check; flash again in that case.
- The update restart message says ten minutes (it was three).

## Updating

From v0.4.0: Settings > System > Check For Updates, Apply, Restart. From earlier versions, write the image to the card
(your data partition is kept).

## Known issues

- Slow, as before (Steam's UI is Chromium on four Cortex-A53 cores and 1 GB of RAM); no sleep and wake yet.
- The update install shows text progress on the console only, and keeps the device busy for about ten minutes.

# SteamOSXX v0.2.1: smoother memory, SSH from the boot partition

## What's new

- **Smoother under memory pressure.** zram now uses lzo-rle for live swapping and recompresses idle pages with zstd in
  the background (`sxx-zram-recompress`). On Geometry Wars that cut memory stall time by about 45% and kernel
  reclaim CPU by about 47% compared with zstd alone, with the same start time and the same capacity. Measurements and
  method: `docs/findings.md`.
- **SSH without adb.** Copy `authorized_keys.example` to `authorized_keys` on the boot partition and paste your public
  key; it is installed for root and steam at the next boot (`ssh root@rg40xx.local`).
- **Sleep can no longer freeze the handheld.** Sleep is not supported yet, so the OS now refuses it: Steam's power
  menu "Sleep" does nothing instead of risking a hung suspend. Restart and Shut down work.
- **Rumble** is forwarded from Steam to the built-in pad through InputPlumber's Steam Deck controller.
- Internal: a repeatable memory benchmark (`tools/membench.sh`), a faster image build path, and CI that no longer
  rebuilds for docs-only pushes.

## Installing

Write the image to a card as in the v0.1.0 notes (`wifi.txt` on the boot partition, card in slot 1). There is no
in-place upgrade from earlier releases.

## Known issues

- **It is slow.** Steam's UI is Chromium on four Cortex-A53 cores and 1 GB of RAM; Geometry Wars: Retro Evolved runs
  at about 6 to 9 FPS and a first launch takes one to three minutes. A launch reads about 740 MB from the SD card
  when the cache is cold, so a faster card helps.
- **No sleep or wake.** Needs low-level suspend work.
- **The GPU cannot run DXVK or gamescope** (PanVK on this Mali is Vulkan 1.0 only).
- After an unclean shutdown Steam spends a few minutes verifying its files before it starts.
- **adb over USB is a root shell** without a password; SSH accepts only the keys you install.
- The first start downloads about 1 GB and needs Wi-Fi from `wifi.txt`.
- Only tested on one RG40XX-H with LPDDR4. Other units may need different RAM timings.

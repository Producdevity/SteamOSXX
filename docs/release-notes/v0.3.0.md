# SteamOSXX v0.3.0: updating no longer wipes your games

Everything you accumulate now lives on its own **data partition**, so writing a new image to the card keeps your Steam
install, Proton, games, the Steam login and your Wi-Fi and SSH settings.

## What's new

- **Persistent data partition.** The image holds the boot partition and a fixed 3 GiB root; the first boot creates a
  third partition, `sxxdata`, from the end of the root to the end of the card and mounts it at `/home`. A later flash
  rewrites only the boot and root partitions: the first boot after it finds the data partition at the same offset and
  reuses it. Verified on hardware: flash, install Steam, flash again, nothing lost, no re-download.
- **Wi-Fi and SSH survive a reflash.** `wifi.txt` and `authorized_keys` from the boot partition are mirrored into the
  data partition and used again when a new image's boot partition no longer has them.
- **The setup window explains itself offline.** With no network it now says how to get Wi-Fi (`wifi.txt` on the boot
  partition) instead of waiting silently.
- Internal: `sxx-gametest` cancels and reports Steam's "playing on another computer" dialog (it never continues,
  which would end your other session) and dismisses the controller hint; the dev reflash script keeps muOS's mount from
  corrupting a flash.

## Updating

Write the image to the same card as before (balenaEtcher or `dd`; anything that writes just the image). **The first
time**, a card from v0.2.1 or earlier has a different layout, so it starts with a fresh data partition and Steam is
downloaded again; from then on updates keep everything. A tool that erases the whole card, or a smaller card, also
starts fresh.

## Known issues

- **It is slow.** Steam's UI is Chromium on four Cortex-A53 cores and 1 GB of RAM; Geometry Wars: Retro Evolved runs
  at about 6 to 9 FPS and a first launch takes one to three minutes.
- **No sleep or wake.** Needs low-level suspend work.
- **The GPU cannot run DXVK or gamescope** (PanVK on this Mali is Vulkan 1.0 only).
- After an unclean shutdown Steam spends a few minutes verifying its files before it starts.
- **adb over USB is a root shell** without a password; SSH accepts only the keys you install.
- The first start downloads about 1 GB and needs Wi-Fi from `wifi.txt`.
- Only tested on one RG40XX-H with LPDDR4. Other units may need different RAM timings.

# SteamOSXX v0.4.0: updates from Steam

You can now update the OS from Steam itself: **Settings > System > Check For Updates**, then Apply, then Restart.

## What's new

- **In-place OS updates.** Steam's own Software Updates row works: it finds the newest release on GitHub, downloads it
  (about 340 MB, checked against its SHA-256), unpacks it onto the data partition and installs it at the next restart. The
  restart writes the new root partition and boot files with a progress count on screen and takes about ten minutes on an
  SD card, so keep the device powered. Your games, Proton, Steam login and Wi-Fi and SSH settings are not touched. If power
  fails midway, the next boot repeats the install. Also from a shell: `sxx-update check`, `sxx-update apply`.
  A release that cannot be installed this way says so in its notes and needs a reflash; U-Boot is never replaced by an
  update.
- **First release with the updater: flash this one.** An image from v0.3.0 has no updater, so v0.3.0 to v0.4.0 is a
  normal flash (your data partition is kept, as in v0.3.0); from v0.4.0 on, updates come through Steam.
- The kernel now has DAMON and zram entry access-time tracking, for memory experiments. Nothing is switched on: DAMON
  reclaim showed no gain on the memory benchmark (docs/findings.md).
- Findings recorded: lowering the Steam web helper's CPU priority does not speed up game launches, and in-game controls
  work through Proton (Geometry Wars menus driven by the pad).

## Known issues

- Slow, as before: Steam's UI is Chromium on four Cortex-A53 cores and 1 GB of RAM.
- No sleep and wake yet. The update restart shows text on the console, not a graphical progress screen.
- The first restart after an update regenerates the SSH host keys, so SSH clients warn about a changed host key.
